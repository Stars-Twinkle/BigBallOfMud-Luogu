# BigBallOfMud Luogu

洛谷新版前端（columba / lfe）的**液态玻璃**美化 + **深浅双模式**。

**只需要装一个油猴脚本** —— 样式已经打包进脚本里，由它在 `document-start` 注入
（比 Stylus 还早，不会闪白）。**不用装 Stylus，也不用装任何 UserCSS**。

脚本自己负责两件事：注入全部外观，以及页面内可点的三态配色开关、深色下的**对比度校正**。

## 都美化了哪些地方

- **液态玻璃质感**：不是单纯的毛玻璃 —— 有镜面光斑、亮上缘 / 暗下缘的"厚度"、内发光、
  以及靠强模糊 + 高饱和让背景颜色透上来的通透感；鼠标悬停时光斑会缓慢漂移
- **顶栏**：左右两个独立的玻璃胶囊，中间留空；高度与留白全站统一
- **左右侧栏**：悬浮胶囊（离开屏幕边缘 + 大圆角），滚动条隐藏，展开/收起状态各自正确
- **背景图**：透出到整页（洛谷默认只画顶部 400px 且有一层不透明底板挡住了图）
- **深色模式**：覆盖洛谷运行时注入的调色板令牌、写死的浅色文字、白底控件、
  各类弹窗与编辑器（SweetAlert2 / CodeMirror 6 / Casket / 题目排序面板 / 评测测试点方块…）
- **链接悬停**：渐变色文字 + 下划线从中间划入（犇犇、讨论区、文章正文都覆盖）
- **标签 / 徽章悬停**：一道高光扫过 + 轻微抬起
- **卡片、按钮、表单、浮层**：同一套玻璃语言，并带柔和阴影与悬停反馈
- **洛谷网校**（`class.luogu.com.cn`）：首页、播放页（课堂）、学习中心的侧栏 / 顶栏 / 播放区 /
  控制条 / 聊天面板与输入框 / 课程卡 / 分类卡 / 页脚 / 标签栏，都按各自前端产物逐条适配，
  深浅色与玻璃一致；「学习体系」那张大图抠掉底板后由玻璃承载

## 自定义机制（想调一调？）

### 三个入口

| 入口 | 在哪 | 管什么 |
|---|---|---|
| **顶栏按钮** | 顶栏那个圆形图标 | 跟随系统 / 深色 / 浅色三态循环，选择被记住（这是**唯一**的配色入口）|
| **样式里的 CSS 变量** | 样式 ② 段（玻璃参数）、③ 段（光泽与文字色）、⑭ 段（背景图） | 外观的全部数值：透明度、模糊、圆角、尺寸、颜色、背景图 |
| **脚本里的 CONFIG** | `bigballofmud-luogu-switch.user.js` 顶部的 `var CONFIG = { … }` | 行为开关：配色按钮、对比度守卫、守卫门槛、防抖时长、调试日志 |

> 改完 CSS 变量要 **Ctrl+S 保存 + 页面 Ctrl+F5**；改脚本要 **Ctrl+S**（篡改猴即时生效，一般不必刷新）。
> 样式里所有可调项都集中在上面那几段，**不必翻全文**：搜索变量名即可（变量名都以 `--lg-` 或 `--sl-` 开头）。

### 哪些东西跟着「洛谷主题商店」自动变

基本约定：**样式自己接管背景与玻璃的呈现**，主题商店只负责"给你选的东西"。
所以下面这张表要配合上一节的「设置变少」一起看 —— 被隐藏的那几项，对应的跟随关系也就断了。

| 项目 | 跟随主题？ | 现在的实际行为 |
|---|---|---|
| **背景图**（编辑器里的「背景图」那一项）| **跟随** | 你填的地址会被脚本读到，搬到 `<html>` 当画布背景（首页与网校复用同一张）|
| ↳ 背景图的**尺寸 / 重复 / 位置** | **不跟随** | 对应设置项已隐藏，画布统一 `cover` + `fixed` + `center` |
| **导航背景** | **跟随** | 这一项保留，顶栏胶囊与左右侧栏都消费 `--theme-navi-back` |
| **Logo 颜色** | **跟随** | 这一项保留 |
| **导航文字 / 图标颜色** | **固定为默认白** | 对应的「文字颜色」项**会先固定回白色再隐藏**（它同时影响图标，而深色下选什么都渲染成白）|
| **页面底色 / 中景颜色** | **不再跟随** | 对应的「背景底色」「中景颜色」已隐藏，底色由画布背景 + 压暗层决定 |
| **卡片底色** | **不再跟随** | 卡片玻璃的底色由本样式的 `--lg-alpha` 与画布背景合成，不再读主题的卡片色 |
| **洛谷的语义色**（标签、难度、AC/WA、`lcolor-*`）| **原样保留** | 一律不动，包括我们新加玻璃的那批标签（只叠玻璃，不改它们的底色）|
| **正文与次要文字颜色** | **不跟随** | 用 `--lg-text` / `--lg-text-weak`，保证深浅两种模式下都可读 |
| **深色模式的底色** | **不跟随** | ③-c 段那六个 `--lg-*-dark` 是我们给的一套暗值（主题基本只配浅色）|
| **毛玻璃等级** | **不跟随** | 洛谷的 `theme-frosted` 伪元素已关闭，全站统一用 `--lg-blur` / `--lg-card-blur` / `--lg-sat` |

**一句话**：**背景图、导航背景、Logo 颜色**这三样由你在主题商店里决定，其余外观都由样式的变量控制。

> ⚠️ 别把样式里浅色分支的 `--theme-*` 改成固定颜色 —— 那会锁死主题色，主题商店换色时玻璃就不跟着变了（早期踩过）。

### 玻璃通透度（数值越小越透）

| 变量 | 默认 | 管什么 |
|---|---|---|
| `--lg-alpha` | `18%` | 主卡片 |
| `--lg-alpha-soft` | `13%` | 列表 / 表格 / 分页 / 搜索框 |
| `--lg-alpha-pop` | `18%` | 模态 / 下拉 / 气泡 / 通知（与卡片同值，避免色差）|
| `--lg-alpha-field` | `36%` | 输入框 / 文本域 / 下拉选择 |
| `--lg-nav-alpha` | `34%` | 顶栏两个胶囊 + 左右侧栏 |

### 液态玻璃质感

| 变量 | 默认 | 作用 |
|---|---|---|
| `--lg-blur` | `24px` | 浮层 / 顶栏 / 侧栏的模糊半径（越大越"液态"）|
| `--lg-card-blur` | `18px` | 卡片模糊（页面卡顿就调小，或设 `0`）|
| `--lg-sat` | `215%` | 背景饱和度提升（越高越能"看见"背景的颜色）|
| `--lg-spec` | `22%` | 镜面光斑强度（设 `0` 退回普通毛玻璃）|
| `--lg-rim` | `62%` | 上缘高光强度（玻璃厚度感）|
| `--lg-shade` | 见 ③-b | 背光侧暗缘（有它才有体积感）|
| `--lg-glow` | 见 ③-b | 内发光 |

|---|---|---|

| `--lg-topbar-gap` | `6px` | 胶囊与顶栏上下边缘的留白 |
| `--lg-radius` / `-sm` / `-xs` | `20 / 12 / 8px` | 大卡 / 中卡 / 小元件圆角 |
| `--lg-side-gap` | `10px` | 侧栏离屏幕边缘的距离 |
| `--lg-side-radius` | `26px` | 侧栏圆角 |
| `--sl-switch-duration` | `.14s` | 切深浅时的统一过渡时长 |

### 背景图

**默认行为：跟着洛谷主题商店走** —— 样式里 `--sl-bg-image` 是**留空**的，
由脚本去读洛谷主题设置的图（`--theme-body-image`，洛谷把它放在 `.theme-page` 上，
真正画图的是 `.theme-page::before`；`<html>` 上取不到这个变量，所以必须由脚本搬一次），
把结果写到 `<html>` 的 `--sl-bg-active`。
**分三种情况**：① 读取到地址 → 用它；② 主题里那一项**被清空** → 回滚成洛谷自己的默认中景图
（`luogu4-bg-l/d`）并清掉缓存；③ 页面还没渲染出 `.theme-page`（或旧首页本来就没有）→ 只用手上的缓存，缓存也空就什么都不写，**故意不写默认图**，免得先闪一下再被真图替换。

> ⇒ **要用主题商店的背景图，脚本必须装**。缺脚本时画布上没有图，只剩底色（与压暗层）。

**脚本侧的抓取规则**（不用改，只是说明）：主站**每次页面更新**先把缓存作废、再重新读一次中景图并写回缓存；
网校与首页自己页面上没有这个变量，直接**复用缓存**；缓存用篡改猴的跨域存储（`GM_setValue` / `GM_getValue`）——
`localStorage` 是按域名隔离的，网校读不到主站存的。

### 主题编辑器里为什么「设置变少了」

脚本会把洛谷主题编辑器（`/theme/…`）里**与美化冲突**的那几项直接隐藏，所以你会看到设置项比原版少。这是有意的：本样式自己接管了背景与玻璃的呈现，那些参数留着只会互相打架（有的还会让渲染不对）。

| 被隐藏的项 | 为什么 |
|---|---|
| **卡片毛玻璃** | 美化是照默认的「**标准**」档写的，选「关闭 / 轻量」会导致渲染不对。脚本会**先把档位拉回「标准」再隐藏** |
| **渐变角度 / 中景亮度 / 中景淡出** | 背景的呈现由本样式接管（画布 + 压暗层），这几个参数进去会互相打架 |
| **图片重复 / 图片尺寸 / 图片位置 X / Y** | 同上。画布统一用 `cover` + `fixed`，由样式决定 |
| **背景底色 / 中景颜色** | 与画布背景、玻璃底色冲突 |
| **亮色主体**（区块标题） | 它下面那几项都已隐藏，标题留着没有意义 |
| **文字颜色** | 它**同时影响图标**，而深色模式下不管选什么颜色最后都会渲染成白，所以脚本会**先把它固定回默认白色再隐藏** |

**保留下来的项**：**导航背景**、**Logo 颜色**、以及 **「背景图」**。

> 最后那个是把原来的「中景图片」改了名字（脚本原地改文案）—— 它就是**唯一还需要你设的一项**。
> 填进去的地址决定全站用哪张背景图，首页与网校会在你打开一次主站内页后跟着用同一张。

> 想恢复被隐藏的项：把脚本里 `THEME_HIDE_PREFIX` 数组中对应的那一行删掉即可（在 `tweakThemeEditor()` 上方）。
> 两项「前置动作」（卡片毛玻璃 → 标准、文字颜色 → 白）在 `tweakThemeEditor()` 里有单独的注释说明。

### 脚本侧的开关（`CONFIG`）

改 `bigballofmud-luogu-switch.user.js` 顶部的 `CONFIG` 即可：

| 键 | 默认 | 作用 |
|---|---|---|
| `showToggle` | `true` | 是否在顶栏放那个三态配色按钮 |
| `contrastGuard` | `true` | 是否启用深色下的对比度守卫 |
| `guardSkipInlineColor` | `true` | 跳过"洛谷自己写了内联 color"的元素（尊重它的语义色）|
| `guardSkipColorChip` | `true` | 跳过彩色徽章 / 标签整棵子树（彩底配的字是洛谷按底色配好的，量对比度没有意义）|
| `guardMinRatio` | `4.5` | 低于这个对比度才动手（WCAG AA）|
| `guardTargetRatio` | `6.0` | 修正到"清楚可读"即可，不追求纯白（调太高会把层次抹平）|
| `guardMaxNodes` | `4000` | 单次扫描元素上限（防御性）|
| `mutationDelay` | `600` | 页面变化后重跑守卫的防抖毫秒数 |
| `switchFallbackMs` | `150` | 读不到 CSS 变量时，切换过渡的兜底时长 |
| `debug` | `false` | 打开后会在控制台打守卫的判定过程 |

### 其它零散变量

| 变量 | 默认 | 作用 |
|---|---|---|
| `--sl-switch-duration` | `.14s` | 切深浅时全站统一的过渡时长 |
| `--lg-highlight` / `--lg-border` / `--lg-sheen` / `--lg-inner` | 见 ③ 段 | 玻璃的高光 / 描边 / 缎面 / 内阴影（想整体换一档"玻璃配方"就动这四个）|
| `--lg-rim-color` / `--lg-spec-color` / `--lg-glow` / `--lg-shade` | 见 ③-c 段 | 上缘高光 / 镜面光斑 / 内发光 / 背光侧暗缘的颜色（深浅各一套）|
| `--lg-panel-dark` / `--lg-nav-dark` / `--lg-soft-dark` / `--lg-pop-dark` / `--lg-field-dark` / `--lg-block-dark` | 见 ③-c 段 | **深色模式**下六档玻璃的底色（浅色模式消费主题变量，所以这里只有深色值）|

**想固定成你自己的图**：把样式里这一行填上即可 —— 脚本检测到它有值就**完全不插手**：

```css
--sl-bg-image: url("https://…");   /* 填了之后脚本不管背景图 */
```

**想彻底交回主题商店**（不要压暗、也不要兜底图）：删掉样式里 ⑭ 整节。

## 常见问题

**Q：装上之后右栏收不回去了？**
已经修好了。如果你想改侧栏悬浮参数：`--lg-side-gap`（离边缘距离）、`--lg-side-radius`（圆角）。

**Q：深色下某处还是白的 / 某段文字看不清？**
两件事可以试：
1. 确认脚本是最新版（篡改猴管理面板 → 「检查更新」；或比对 `@version` 日期）
2. 装上脚本（必需）—— 它的「对比度守卫」会读取**最终计算出来**的颜色，自动把不达标的文字修到可读

**Q：浅色模式和洛谷原版一样吗？**
一样。样式的浅色分支一律"就地消费"洛谷的主题变量，且深色重映射用的浅色值都等于洛谷原值
（本项目有一套校验脚本专门断言这一点）。

**Q：首页那块广告轮播能藏掉吗？**
能。样式的做法是「**默认显示**」——广告保持洛谷原样，
所以在样式里搜 `把下面两行取消注释即可`（或直接搜 `#lg-slider`），
把那段被注释掉的规则放开即可，**同时**要把紧跟着的 `.lg-punch`（打卡/日历列）也放开到整行，
否则左边会空出 2/3。两段都写在一起了，一起放开就行。

**Q：会和洛谷主题商店冲突吗？**
不会。样式不重写主题变量，只是消费它们；换主题色、换背景图，玻璃都会跟着变。

**Q：页面变卡？**
把 `--lg-card-blur` 调小（如 `8px`）或设 `0`；也可以把 `--lg-sat` 降到 `150%`。

**Q：手机上能用吗？**
未测试。样式是按桌面布局写的（顶栏胶囊、左右侧栏），移动端布局不同，可能需要另外适配。

## 兼容性

- **浏览器**：需要支持 `light-dark()`，即 Chrome / Edge 111+、Safari 16.4+、Firefox 120+。
  更老的浏览器会退化：文件里有 `@supports not (color: light-dark(#fff, #000))` 兜底块，
  保留固定浅色玻璃（深色模式不生效）。
- **站点范围**：主站 `www.luogu.com.cn` 与**网校** `class.luogu.com.cn`（首页 / 播放页 / 学习中心等
  已按各自产物适配，深浅色与玻璃都覆盖）。
  `ti.luogu.com.cn`（有题）是另一套前端，暂不覆盖。
- **随洛谷更新可能失效**：洛谷前端发版会改 DOM 结构与类名。本样式**刻意不使用** `data-v-*` 哈希
  （每构建都会变），但仍然依赖稳定的语义类名，洛谷大改版后个别地方可能需要跟进。
